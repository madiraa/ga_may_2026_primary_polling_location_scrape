SHEET STATUS TAGS (col P)

New location appeared on the SOS site. Auto-clears next stable run.
MODIFIED: hours_raw 04/24
One or more fields changed. Lists which fields. Auto-clears when data stabilizes.
REMOVED 04/24/2026
Location disappeared from SOS site. Row kept in sheet. Clears if location reappears.
